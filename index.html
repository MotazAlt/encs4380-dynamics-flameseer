Project overview

TEAM 10

Sensors take time to follow their inputs, and feedback loops depend on how quickly and accurately those readings arrive. This toolkit makes sensor dynamics and closed-loop PID control visible through interactive models, live plots, and a sensor-identification challenge.

Using the toolkit

  1. Make a prediction in a module's “Predict, then check” box.
  2. Move the sliders and compare the plotted response with the live measurements.
  3. Use the Validation Suite to verify the analytical models against reference benchmarks.
  4. Open P1: PID Playground or P2: Slow Sensor in the Control section.
  5. Try “Guess the sensor” and estimate τ, or ζ and ωn, from a noisy curve. Estimates within 10% receive full marks.

Models & measurement conventions

The plots use the closed-form first-order and mass-spring-damper responses. Module 3 links displacement x1 and velocity x2 to A = [[0, 1], [−k/m, −b/m]], B = [[0], [1/m]], C = [1, 0], and D = 0.

Mass m is in kg, damping b in N·s/m, stiffness k in N/m, and ωn in rad/s. A force step F0 = kK N gives final displacement K metres. Rise time uses the first 10%–90% transition; settling time uses the last entry into the ±2% band. Peak time and overshoot are measured from curve samples. Peaks below 0.01% are not marked; an undamped system never settles.

Built with HTML, CSS, JavaScript, and a locally bundled Plotly library. Everything runs in the browser without a backend, account, or network connection. Challenge scores last until the page is reloaded.
