Project overview

TEAM 10

Sensors take time to follow their inputs. This toolkit makes that delay visible through first-order and second-order models, interactive plots, and a sensor-identification challenge. Each module connects a response curve with the equations used to describe it.

Using the toolkit

  1. Make a prediction in a module's “Predict, then check” box.
  2. Move the sliders and compare the plotted response with the live measurements.
  3. Use the Validation Suite to compare the models with the six lecture checks.
  4. Try “Guess the sensor” and estimate τ, or ζ and ωₙ, from a noisy curve. Estimates within 10% receive full marks.

Models & measurement conventions

The plots use the closed-form first-order and mass-spring-damper responses. Module 3 links displacement x₁ and velocity x₂ to A = [[0, 1], [−k/m, −b/m]], B = [[0], [1/m]], C = [1, 0], and D = 0.

Mass m is in kg, damping b in N·s/m, stiffness k in N/m, and ωₙ in rad/s. A force step F₀ = kK N gives final displacement K metres. Rise time uses the first 10%–90% transition; settling time uses the last entry into the ±2% band. Peak time and overshoot are measured from curve samples. Peaks below 0.01% are not marked; an undamped system never settles.

Built with HTML, CSS, JavaScript, and a locally bundled Plotly library. Everything runs in the browser without a backend, account, or network connection. Challenge scores last until the page is reloaded.
